## Plan
- **Slice:** a page that fails anywhere, including in its own page-tree entry, becomes an error page under its own number while every other page is written; bad, truncated and encrypted input gives a one-line error and exit 2; a broken cross-reference table is repaired through PDFium. Concretely, from `design.md` (Adapter section, Decisions, Risks 6, 10, 11):
  - the adapter's own `_walk_pages(doc)` replacing `PDFPage.create_pages`. In this slice each entry's `try` catches `Exception` only; backlog #7 widens it to `StructureTimeout` later, so don't add a watchdog, `StructureTimeout` or `PageTimeout` here;
  - `Document.read_next` replaced by `advance() -> bool` and `read() -> RawPage`, with the entry's failure stored by `advance` and raised by `read`; `page_number` counts failed entries; `page_bbox` reset to `BBox(0, 0, 0, 0)` in `advance` and set only to a finite box in `read`;
  - opening in the order: size check, zlib shim, `pdfplumber.open`, `doc.caching = False`, read `/Count`, first page-tree step;
  - failure classification and PDFium repair in memory, never `repair=True`; the page-1 rule (repair first; repaired document if its first entry is good, else the original with a page-1 error page);
  - the page exception boundary in `api.py` around `read` and `compose_page`, exit 3 from the CLI when any page failed;
  - backlog #10 (`page_bbox` kept from the previous page), #11 (NUL in the path lets `ValueError` escape), #12 (a read error during parsing reported as `cannot write output`, exit 1, instead of exit 2), #13 (the AC-2 spy moves to `advance` and `read`).
- **Criteria:** AC-17, AC-18, AC-19, AC-20, AC-21, SEC-8, SEC-14, SEC-15, SEC-17, and SEC-16's clause for `/MediaBox 99 0 R` on page 3 (its cycle clauses need #7's watchdog and are not in this slice)
- **Invariants it could affect:** INV-1 (tested); AC-1 and AC-2 behaviour already verified (must still pass)
- **Patterns:** PAT-1 (exemplar `src/pdftext/model.py`), PAT-2 (exemplar `src/pdftext/adapter.py`: the walker and all pdfminer and pypdfium2 imports stay in it), PAT-3 (exemplar `src/pdftext/text.py`), PAT-4 (exemplar `src/pdftext/xmlwriter.py`)
- **Files likely touched:** `src/pdftext/adapter.py`, `src/pdftext/api.py`, `src/pdftext/cli.py`, `src/pdftext/errors.py`, `tests/pdfgen.py`, `tests/test_adapter*.py`, `tests/test_api.py`, `tests/test_cli.py`, new test files for this slice.
