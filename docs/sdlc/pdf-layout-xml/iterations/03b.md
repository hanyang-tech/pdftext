## Plan
- **Slice:** a grid drawn edge to edge inside a parent cell, and aligned text inside a ruled cell, come out as nested tables; every table level, of whatever kind, counts toward `--max-table-depth`. Backlog #4 and #18. Concretely, from `design.md` (Stages contracts for `grids.py`, `borderless.py`, `pipeline.py`; Decisions on nesting and depth; Risk 5; Criteria coverage rows AC-12 to AC-16 and SEC-7):
  - `collapse(grid: GridNode, *, max_levels: int) -> GridNode | None`: infers nested levels from a grid touching its parent cell's borders, under AC-14's rule (nested only if collapsing leaves a plain grid with no merged cells); returns `None` when the result won't fit in `max_levels`, and the grid then stays flat with its spans;
  - `build_forest`: every level (floating, inferred, text-detected) counts toward `max_depth`; parenting searches cells at every inferred level, ties broken on `(area, placement position, cell path)`; a cell's children list its inferred subgrid first (#18);
  - `detect_text_table` in `borderless.py`: aligned text in leaf ruled cells, inferred ones included, becomes a `detection="text"` table with no blank rows; it runs only below `max_table_depth`, so `pipeline.py` passes the depth through;
  - backlog #19 (`populate` O(chars × root grids)) is optional: take it only if it falls out of the `build_forest` change, and say so.
