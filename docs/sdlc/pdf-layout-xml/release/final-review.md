DESIGN ISSUES: Risk 6 in design.md relies on the parser versions being "pinned by the lock", but that only holds for `uv sync`/`uv run`. The README's documented install routes (`pip install .`, `uv tool install .`) ignore uv.lock. pyproject.toml leaves pdfminer.six without an upper bound and pypdfium2 unconstrained. So the five private seams behind SEC-1, SEC-4, SEC-6 and SEC-15 can silently stop working on a fresh install. Either:

(b) add an import-time self-check that fails closed when a seam's target is missing or changed; or
(c) document a lock-respecting install route as the only supported one.
(b) is the most robust and fits Risk 6's intent.
